# Production-Grade Kubernetes on AWS EKS

A comprehensive reference implementation demonstrating production-grade Kubernetes deployment on AWS EKS with Spring Boot microservices, automated GitOps workflows, and infrastructure as code.

## 🎯 What's Inside

- **Spring Cloud Microservices** - Gateway, service discovery, config management, Feign clients
- **Terraform Infrastructure** - Complete EKS cluster, VPC, IAM, Karpenter, ALB Controller
- **AWS CodeBuild CI/CD** - Automated build, ECR push, GitOps repository updates
- **ArgoCD GitOps** - Declarative deployment with App of Apps pattern
- **Auto-Scaling** - HPA for pods, Karpenter for intelligent node provisioning
- **Multi-Environment** - Local development, Docker Compose, Kubernetes deployment
- **Security Best Practices** - EKS Pod Identity, RBAC, private API endpoints, secrets management
- **Comprehensive Documentation** - Architecture diagrams, deployment guides, troubleshooting

## 🚀 Key Features

✅ Fully automated infrastructure provisioning with Terraform  
✅ Production-ready EKS cluster with managed node groups  
✅ Spring Boot microservices with Kubernetes-native service discovery  
✅ Automated CI/CD pipelines with AWS CodeBuild  
✅ GitOps deployment workflow with ArgoCD  
✅ Intelligent auto-scaling with Karpenter and HPA  
✅ Multi-environment support (local, Docker, Kubernetes)  
✅ Comprehensive monitoring and health checks  
✅ Security hardening with IAM roles and RBAC
